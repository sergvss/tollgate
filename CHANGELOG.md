# Changelog

Версии по [SemVer](https://semver.org/lang/ru/). Версия хранится в `tollgate.py` → `__version__` и в git-тегах `vX.Y.Z`.

## [0.3.0] - 2026-10-02

- Тёмная тема (в настройках): тёмная палитра и тёмная рамка окна Windows 11
- Масштаб интерфейса: 100% и 125% - шрифты, отступы и полоски
- Экран настроек: три группы - язык, тема, масштаб; помещается в размер панели лимитов, окно не прыгает
- Тема и масштаб сохраняются в `~/.tollgate/state.json`

## [0.2.3] - 2026-10-02

- Боковые отступы панели меньше: 16px вместо 22px

## [0.2.2] - 2026-10-02

- Всё по одной сетке: левые края (название, провайдеры, подписи окон) и правые (пин, возраст данных, время сброса) на одной линии
- Колонки процента и времени фиксированной ширины по самому длинному тексту - сетка не гуляет при обновлениях
- Срок подписки Claude без «≈»

## [0.2.1] - 2026-10-02

- Панель больше не мерцает при обновлении: элементы создаются один раз, дальше меняются только значения
- Изменение процентов анимируется (полоска и число плавно доезжают, ~0.3 с)
- Возраст данных коротко и тикает каждую секунду: 12с, 3м, 2ч, 1д; у провайдеров - со значком часов
- Время до сброса сразу за процентом, без большого отступа
- Срок подписки: 31д вместо 31 дн
- Иконка трея и позиция окна обновляются только при реальных изменениях

## [0.2.0] - 2026-10-02

- Настройки (шестерёнка в шапке) открываются в том же окне и в том же размере
- Три языка интерфейса: русский, English, 中文. Выбор сохраняется, статус-строка Claude Code тоже переводится
- Значок обновления в шапке вместо слова «обновлено»: возраст самых свежих данных, по клику - обновить вручную
- Короткие подписи окон: 5ч, 1д, 1н
- Срок подписки (дата и дни) - справа от плашки тарифа, без отдельной строки
- Исправлено: панель «прыгала» при переключении пина и при обновлении (двойная буферизация)

## [0.1.1] - 2026-10-02

- Шапка панели: название и версия слева, время обновления и пин справа
- Пин виден по форме: откреплён - серый контур с наклоном, закреплён - залитый и вертикальный (Windows 10 и 11)

## [0.1.0] - 2026-10-02

Первый релиз.

- Иконка в трее Windows: две полоски (Claude и Codex) с цветом по заполнению, подсказка с цифрами при наведении
- Светлая панель со скруглёнными углами: появляется справа снизу с отступом 25px
- Лимиты Claude Code (5ч и неделя) и Codex (окна подписки ChatGPT), время до сброса
- Свежие данные Claude после каждого ответа через статус-строку (`statusline.py`)
- Тариф и срок подписки: Codex точно, Claude оценкой
- Уведомление Windows и автопоказ панели при 80% и 95%, подсветка заканчивающихся окон
- Пин: закреплённая панель всегда на экране и остаётся после перезапуска
- `install.bat`: зависимости, статус-строка, автозапуск, защита от второго экземпляра
