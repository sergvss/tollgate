# Правила для ИИ-ассистентов в этом репозитории

Перед работой прочитай [PROJECT_MAP.md](PROJECT_MAP.md): архитектура, источники данных, принятые решения и грабли, которые уже пройдены.

## Язык
- Общение, комментарии в коде и сообщения коммитов - на русском.
- Коммит начинается с глагола: «Добавить …», «Исправить …», «Обновить …», «Удалить …», «Переработать …».
- В текстах интерфейса - обычный дефис (-), не длинное тире.
- Новые строки интерфейса добавлять во все три языка `STRINGS` (ru, en, zh).

## Принципы проекта
- Только локальные данные: сам Tollgate в сеть ничего не отправляет. Единственное исключение - фоновый запуск `claude -p /usage` (`refresh_claude_usage`): запрос делает Claude Code, Tollgate токены не читает.
- Токены из `~/.codex/auth.json` и `~/.claude/.credentials.json` не использовать и не выводить. Из `auth.json` читается только payload `id_token` (поля подписки).
- Чужие настройки пользователя (`~/.claude/settings.json` и др.) не перетирать; перед правкой - бэкап.
- Простота: минимум кода под задачу, без спекулятивных абстракций; правки хирургические, в стиле окружающего кода.

## Интерфейс - не ломать
- Панель обновляется **на месте**; полная пересборка - только при смене `_layout_key`. Не возвращать пересоздание всех виджетов на каждом обновлении - это мерцание.
- Экраны лимитов и настроек хранятся готовыми (`self.screens`): переключение - подмена готовой рамки, без пересборки (~20 мс вместо ~60 мс, без дорисовки по частям). Подмена - одним кадром под `_freeze()` (WM_SETREDRAW): размер окна тоже меняется под заморозкой, после разморозки - сразу `update_idletasks()`. Экран настроек собирается заранее в простое (`_prebuild_settings`), так что и первое открытие - подмена. Прелоадер пользователь предлагал - отказались: переключение слишком быстрое, он бы только мелькал, а в однопоточном tkinter во время сборки и не анимировался бы.
- Окно одно; второе окно-«призрак» и гашение окна целиком пользователь отклонил.
- Выравнивание по сетке (`self.ip`, `_grid_columns`, `_fit_bars`) - левые и правые края всех строк совпадают; проверять после правок вёрстки.
- Ширина окна у лимитов и настроек одинаковая на всех языках/темах/масштабах; высота у каждого экрана своя (решение пользователя, 0.6.1), правый нижний угол на месте.
- Цвета берутся из глобалов текущей темы во время вызова: значения по умолчанию `bg=None`, не `bg=BG`.

## Проверка перед коммитом
- `python -m pytest -q` - тесты зелёные (их же гоняет GitHub Actions на каждый push).
- `python -X utf8 tollgate.py --print` - данные читаются.
- Визуально: скрипт с `Widget`, скриншоты окна (см. PROJECT_MAP.md, раздел 7). В тестах **обязательно** подменять `tollgate.STATE_FILE` и `tollgate.HISTORY_FILE` на временные файлы - иначе тест перезапишет настройки пользователя и засорит его историю замеров.
- Перезапустить работающий виджет (старый экземпляр убить - мьютекс не даст запустить второй).
