# Tollgate

Шлагбаум между тобой и ИИ: видно, сколько потрачено, а дальше - экономия токенов и фильтр запросов.

Версия **0.6.0** ([CHANGELOG](CHANGELOG.md), [план разработки](TODO.md)). Для разработчиков: [карта проекта](PROJECT_MAP.md), [правила для ИИ-ассистентов](AGENTS.md).

Сейчас это иконка в трее Windows (рядом с часами) и всплывающая светлая панель с лимитами **Claude Code** (5ч / неделя) и **Codex** (окна из подписки ChatGPT), тарифом и сроком подписки. Когда лимит подходит к концу, Tollgate сам показывает уведомление и подсвечивает окно, которое заканчивается.

Сам Tollgate в сеть не ходит и токены входа не читает - данные берутся из локальных файлов. Чтобы лимиты Claude были свежими, где бы вы ни работали (терминал, десктоп-приложение, IDE), раз в 5 минут он в фоне запускает `claude -p /usage`: запрос лимитов к Anthropic делает сам Claude Code - тот же, что он делает и без Tollgate, к модели он не обращается и лимит не тратит.

| Что | Claude | Codex |
|---|---|---|
| Лимиты | кэш `~/.claude.json` → `cachedUsageUtilization` (обновляет `claude -p /usage` раз в 5 минут) или `~/.tollgate/claude-usage.json` (пишет `statusline.py` после каждого ответа в терминале) - что свежее | последний `~/.codex/sessions/**/*.jsonl` → событие `rate_limits` |
| Тариф | `~/.claude.json` → `oauthAccount.organizationType` | `~/.codex/auth.json` → `id_token` → `chatgpt_plan_type` |
| Срок подписки | ≈ оценка: месячное продление от `oauthAccount.subscriptionCreatedAt` (дата окончания локально не хранится) | точно: `chatgpt_subscription_active_until` |

Про `~/.codex/auth.json`: файл содержит токены входа Codex. Tollgate декодирует только открытую часть `id_token` (поля про подписку), сами токены не использует и никуда не передаёт.

## Установка

Нужны Windows 10/11 и Python 3.10+ (на python.org при установке отметить «Add python.exe to PATH»).

```
git clone https://github.com/sergvss/tollgate.git
cd tollgate
install.bat
```

`install.bat`:
1. ставит зависимости (`pystray`, `pillow`);
2. прописывает статус-строку Claude Code (`statusline.py`) в `~/.claude/settings.json`, чтобы лимиты Claude обновлялись после каждого ответа. Если у тебя уже есть своя статус-строка, она не трогается (данные Claude тогда будут обновляться реже). Перед правкой сохраняется бэкап `settings.json.bak-tollgate`;
3. кладёт ярлык `Tollgate.lnk` в автозагрузку и запускает виджет. Повторный запуск не создаёт второй экземпляр.

Удаление: `uninstall.bat` - останавливает виджет, убирает ярлык из автозагрузки и статус-строку Tollgate из `~/.claude/settings.json` (чужую статус-строку и остальные настройки не трогает, перед правкой сохраняет бэкап `settings.json.bak-tollgate-uninstall`). Папку `~/.tollgate` (настройки виджета) и папку проекта после этого можно удалить вручную.

Проверка без окна: `python -X utf8 tollgate.py --print`. Тесты: `python -m pip install pytest`, затем `python -m pytest -q`.

## Управление

- Иконка: две полоски - Claude и Codex, заполнены по самому загруженному окну, цвет зелёный / жёлтый / красный. Наведение - подсказка с цифрами.
- Левый клик по иконке - показать/скрыть панель (справа снизу, отступ 25px от краёв рабочей области).
- Панель прячется по клику мимо или Esc.
- Шапка панели справа: стрелка обновления и возраст самых свежих данных - 12с, 3м, 2ч, 1д (клик по стрелке - обновить вручную), шестерёнка, пин. У каждого провайдера - значок часов и когда были последние данные.
- Пин - закрепить: панель всегда на экране и остаётся после перезапуска.
- Шестерёнка - настройки в том же окне: язык (русский, English, 中文), тема (светлая, тёмная), масштаб (100%, 125%), пороги уведомлений (Выкл, 95, 80/95, 70/90) - переключатели-«пилюли» с плавной анимацией. Всё сохраняется; язык действует и на статус-строку Claude Code.
- Правый клик по иконке - версия, Показать / Обновить / Выход.
- Данные обновляются раз в 30 с. Подписи окон: 5ч, 1д, 1н.
- Прогноз: если при текущем темпе лимит кончится раньше сброса, вместо времени сброса жёлтым показано, через сколько он кончится (`~40м`). Темп считается по последнему часу работы; если данных меньше чем за 10 минут или они старше 30 минут, прогноза нет. Для этого Tollgate хранит замеры лимитов за 7 дней в `~/.tollgate/history.jsonl` (только проценты и время, без текстов запросов).
- Справа от плашки тарифа - дата окончания подписки и сколько дней осталось (у Claude дата оценочная - месячное продление от даты оформления).

Уведомления: при 80% и 95% любого окна (пороги меняются в настройках, «Выкл» - тихий режим без уведомлений) приходит уведомление Windows, панель сама открывается на 10 с, заканчивающиеся окна подсвечиваются. Срок подписки подсвечивается жёлтым за 3 дня до окончания (и приходит уведомление Windows) и красным после.

Если иконку не видно - она под стрелкой «^» в трее: перетащить на панель задач или включить в «Параметры → Персонализация → Панель задач → Другие значки».

## Ограничения

- Codex обновляет лимиты, только когда им пользуются, поэтому его данные бывают старыми (возраст виден в панели).
- Для автообновления лимитов Claude нужен `claude` в `PATH` (так ставит официальный установщик). Без него данные Claude обновляются только статус-строкой в терминале и редким кэшем Claude Code.
- Если окно лимита уже сбросилось, а новых данных нет - показывается 0% и «сброшен».
