# Tollgate

Шлагбаум между тобой и ИИ: видно, сколько потрачено, а дальше - экономия токенов и фильтр запросов.

Сейчас это иконка в трее Windows (рядом с часами) и всплывающая светлая панель с лимитами **Claude Code** (5ч / неделя) и **Codex** (окна из подписки ChatGPT), тарифом и сроком подписки.

Работает только с локальными файлами, в сеть ничего не отправляет.

| Что | Claude | Codex |
|---|---|---|
| Лимиты | `~/.claude.json` → `cachedUsageUtilization` (кэш Claude Code) | последний `~/.codex/sessions/**/*.jsonl` → событие `rate_limits` |
| Тариф | `~/.claude.json` → `oauthAccount.organizationType` | `~/.codex/auth.json` → `id_token` → `chatgpt_plan_type` |
| Срок подписки | ≈ оценка: месячное продление от `oauthAccount.subscriptionCreatedAt` (дата окончания локально не хранится) | точно: `chatgpt_subscription_active_until` |

Про `~/.codex/auth.json`: файл содержит токены входа Codex. Tollgate декодирует только открытую часть `id_token` (поля про подписку), сами токены не использует и никуда не передаёт.

Срок подписки подсвечивается жёлтым за 3 дня до окончания и красным после.

## Установка

Нужны Windows 10/11 и Python 3.10+ (на python.org при установке отметить «Add python.exe to PATH").

```
git clone <url репозитория>
cd tollgate
install.bat
```

`install.bat` ставит зависимости (`pystray`, `pillow`), кладёт ярлык `Tollgate.lnk` в автозагрузку и запускает виджет. Повторный запуск не создаёт второй экземпляр.

Удаление: «Выход» в меню иконки, затем удалить `Tollgate.lnk` из папки `shell:startup` (Win+R → `shell:startup`).

Проверка без окна: `python -X utf8 tollgate.py --print`

## Управление

- Иконка: две полоски - Claude и Codex, заполнены по самому загруженному окну, цвет зелёный / жёлтый / красный. Наведение - подсказка с цифрами.
- Левый клик - показать/скрыть панель (справа снизу, отступ 25px от краёв рабочей области).
- Панель прячется по клику мимо или Esc.
- Правый клик - Показать / Обновить / Выход.
- Данные обновляются раз в 30 с.

Если иконку не видно - она под стрелкой «^» в трее: перетащить на панель задач или включить в «Параметры → Персонализация → Панель задач → Другие значки».

## Ограничения

Данные свежие настолько, насколько их обновили сами Claude Code и Codex (возраст виден в панели). Если окно лимита уже сбросилось, а новых данных нет - показывается 0% и «сброшен».
